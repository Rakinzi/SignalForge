# Project Summary Template

Use this format for CV, portfolio, LinkedIn, or proposal-style project summaries:

`[Project Name]` `[Primary tech stack]`
Built a `[project type]` that `[primary outcome / core purpose]`
Implemented `[major feature or subsystem 1]`, `[major feature or subsystem 2]`, and `[major feature or subsystem 3]`

## SignalForge Example

**SignalForge**  
Python, FastAPI, SvelteKit, TypeScript, PostgreSQL, Docker

Built a hybrid malware detection platform for encrypted network traffic analysis with explainable, research-grade detection workflows

Implemented deterministic rule-based detection, statistical anomaly scoring, JWT-authenticated REST and SSE APIs, and a real-time SvelteKit dashboard for flows, alerts, entities, and evaluation metrics
